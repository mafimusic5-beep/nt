Политика конфиденциальности Skryon

Дата последнего обновления: 12 сентября 2026 года

Настоящая Политика описывает, какие данные обрабатываются при использовании сайта, приложения и VPN-сервиса Skryon, для каких целей они используются и как пользователь может реализовать свои права.

1. Оператор и контакты

Оператором сервиса является администратор Skryon. По вопросам конфиденциальности, доступа к данным, исправления или удаления данных можно обратиться по адресу support@skryon.ru.

2. Какие данные обрабатываются

Для предоставления сервиса и защиты подписки Skryon может обрабатывать:

  • псевдонимный технический идентификатор устройства и криптографический публичный ключ;
  • отображаемое имя или псевдоним устройства;
  • данные активации, подписки, выбранного региона и назначенного VPN-сервера;
  • служебные сведения о состоянии подписки, устройства и безопасности запросов;
  • сведения о заказах и платежах: идентификатор платежа у платёжного провайдера, сумма, валюта, статус и время платежа;
  • Telegram ID, если пользователь взаимодействует со Skryon через Telegram-бота;
  • обращения в поддержку и сведения, которые пользователь добровольно сообщает в таком обращении.

На Android системное значение ANDROID_ID может локально использоваться приложением для формирования одностороннего псевдонимного идентификатора устройства. Сырое значение ANDROID_ID не передаётся на серверы Skryon и не сохраняется Skryon. Skryon не использует для этой цели IMEI, серийный номер устройства или MAC-адрес.

Закрытый криптографический ключ устройства создаётся и используется в Android Keystore и не передаётся на сервер. Сервер получает соответствующий публичный ключ, необходимый для проверки подписанных запросов устройства.

Skryon не хранит номера банковских карт: платёжные реквизиты обрабатываются платёжным провайдером.

3. VPN-трафик

Skryon не сохраняет историю посещённых сайтов и содержимое пользовательского VPN-трафика в VPN access-логах.

VPN-сервер технически обрабатывает сетевые пакеты только в объёме, необходимом для маршрутизации и предоставления VPN-соединения. Трафик не используется для рекламной монетизации или продажи третьим лицам.

4. IP-адрес и диагностика соединения

IP-адрес неизбежно обрабатывается сетевой инфраструктурой при установлении соединения. Skryon минимизирует серверное журналирование и не ведёт VPN access-логи с историей подключений пользователей.

При запуске функции проверки текущего соединения приложение может обращаться к внешнему сервису определения IP/страны (по умолчанию api.ip.sb) либо к URL, выбранному пользователем. Такой внешний сервис получает сетевой запрос и может обрабатывать IP-адрес по собственной политике конфиденциальности.

5. Список установленных приложений

Функция VPN для отдельных приложений может читать список установленных приложений на устройстве, чтобы пользователь мог выбрать, какие приложения направлять через VPN. Этот список используется локально на устройстве и не передаётся на серверы Skryon в рамках данной функции.

6. Безопасное восстановление после переустановки

Чтобы обычное удаление и повторная установка приложения не занимали новый оплаченный слот устройства, Skryon может распознать ранее зарегистрированное устройство по псевдонимному техническому идентификатору.

Если после переустановки криптографический ключ приложения был утрачен, замена зарегистрированного публичного ключа выполняется через отдельную процедуру восстановления. Она может включать код активации, одноразовый серверный запрос, подпись новым ключом и проверку Google Play Integrity. После успешного восстановления прежний зарегистрированный ключ перестаёт использоваться для доступа.

Skryon не рассматривает один только псевдонимный идентификатор устройства как достаточное доказательство права на доступ.

7. Google Play Integrity

В Android-версии, распространяемой через Google Play, Skryon может использовать Google Play Integrity для проверки подлинности приложения и целостности устройства во время чувствительных операций, в частности безопасного восстановления доступа после переустановки.

Для такой проверки приложение получает токен Play Integrity, связанный с одноразовым запросом Skryon. Сервер Skryon передаёт этот токен в API Google Play Integrity для проверки. Обработка данных сервисом Google регулируется условиями и политиками Google.

8. Для чего используются данные

  • активация и предоставление VPN-подписки;
  • контроль разрешённого количества устройств;
  • аутентификация устройства и защита от злоупотреблений;
  • безопасное восстановление ранее зарегистрированного устройства после переустановки приложения;
  • обработка заказов и подтверждение оплаты;
  • работа поддержки;
  • обеспечение стабильности, безопасности и соблюдение обязательных требований законодательства.

9. Передача третьим лицам

Данные могут передаваться только тем поставщикам услуг, без которых невозможно оказание соответствующей функции, например хостинг-провайдерам, платёжному провайдеру и инфраструктурным сервисам. Для проверки подлинности приложения и устройства при защищённом восстановлении может использоваться Google Play Integrity. При использовании функции проверки IP/страны сетевой запрос может направляться соответствующему внешнему сервису.

Skryon не продаёт персональные данные и не передаёт пользовательский VPN-трафик рекламным сетям.

При выборе VPN-сервера в другой стране сетевой трафик направляется через этот сервер, что является самой функцией VPN.

10. Сроки хранения

VPN access-логи с историей посещений не ведутся. Технические audit-записи хранятся ограниченное время: частые записи проверки состояния узлов — до 7 дней, остальные технические audit-записи — до 90 дней.

Данные подписок, устройств, заказов и платежей хранятся столько, сколько необходимо для предоставления сервиса, разрешения споров, выполнения бухгалтерских и иных обязательных требований законодательства, после чего удаляются или обезличиваются, если дальнейшее хранение не требуется.

Краткоживущие серверные данные, создаваемые для безопасного восстановления устройства, предназначены для выполнения конкретной процедуры восстановления и ограничиваются по сроку действия.

11. Безопасность

Skryon применяет технические и организационные меры защиты, включая шифрование соединения до VPN endpoint, привязку устройства с использованием криптографической пары ключей, подпись чувствительных запросов, одноразовые значения для защиты от повторного воспроизведения запросов, ограничение серверного журналирования и контроль доступа к инфраструктуре.

Закрытый ключ устройства не передаётся серверу Skryon. При поддержке устройством приложение пытается использовать аппаратно защищённое хранилище ключей Android; при его недоступности используется Android Keystore.

12. Права пользователя

Пользователь может запросить сведения об обрабатываемых данных, их исправление или удаление, если хранение не требуется по закону или для защиты законных требований. Запрос направляется на support@skryon.ru. Для защиты аккаунта Skryon может запросить подтверждение, что запрос относится к соответствующей подписке или устройству.

13. Разрешения Android

Приложение использует Android VpnService для создания VPN-туннеля. Перед первым предоставлением системного VPN-разрешения приложение показывает отдельное уведомление о назначении VpnService и запрашивает явное согласие пользователя.

Доступ к камере используется только при запуске пользователем сканирования QR-кода. Широкий доступ к фото и медиатеке для выбора конфигурационных файлов в release-сборке не требуется: используется системный выбор файлов Android.

Для функции выбора приложений, которые должны или не должны использовать VPN, приложение может запрашивать видимость установленных приложений. Полученный список используется локально для настройки маршрутизации.

14. Изменения Политики

Политика может обновляться при изменении функций Skryon, инфраструктуры или требований законодательства. Актуальная версия публикуется по адресу https://skryon.ru/privacy.html.
