# Минимизация данных

## Android-приложение

- Идентификатор установки создаётся локально через `UUID.randomUUID()` и хранится в настройках приложения.
- Идентификатор не вычисляется из Android ID, IMEI, серийного номера, MAC-адреса, рекламного идентификатора, модели устройства или учётной записи.
- В интерфейсе и API используется пользовательский псевдоним. Технические строки эмулятора и модели заменяются на `Android-устройство`.
- Встроенные NDJSON/debug-логгеры отключены и не создают файлы аналитики.
- Синхронизация конфигурации использует существующий переключатель автообновления, выключенный по умолчанию. Активация по коду остаётся явным действием пользователя.

## Сервер

- Приложения FastAPI не используют `request.client.host`, `X-Real-IP` или `X-Forwarded-For` для идентификации пользователей.
- Ограничение частоты запросов использует кратковременные SHA-256 ключи из локального идентификатора установки или данных конкретного запроса.
- Uvicorn access log отключён. Примеры Docker, systemd и Nginx также отключают журналы доступа и передачу IP-заголовков.
- Технические имена устройств очищаются на входе, перед сохранением и при выдаче через API.
- Миграция `0004_privacy_names` заменяет уже сохранённые технические названия на общий псевдоним.

## Эксплуатационное требование

Публичный CDN, балансировщик или reverse proxy должен быть настроен без журналирования IP-адресов. Код приложения не может удалить журналы, которые создаёт внешний провайдер вне инфраструктуры проекта.
