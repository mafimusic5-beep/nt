# Skryon Windows через действующего Telegram-бота

Это расширение **существующего** `skryon-bot.service` из `emery vpn orchestrator`. Второго бота с тем же токеном запускать не нужно.

## Рабочий процесс

1. На компьютере издателя соберите и протестируйте Windows-установщик. Для публичного релиза используйте Authenticode.
2. На этом же ПК выполните `tools/Prepare-Telegram-Release.ps1` из Windows-проекта. Скрипт создаёт 18-МиБ части `*.skpart` и **подписанный** `SkryonRelease-<buildId>.json`. Закрытый ключ ECDSA хранится в Windows CNG и не экспортируется.
3. В личном чате администратора бота откройте **Windows-релизы** или отправьте `/release`. Передайте все части `*.skpart`, затем JSON. Бот проверит сборку, SHA-256 и подпись точно тем публичным ключом, который использует Windows-клиент.
4. Просмотрите версию, код сборки, сигнатуры и нажмите **«Опубликовать»**, затем подтвердите ещё раз. Бот выкладывает EXE через SFTP, проверяет удалённый хеш и атомарно заменяет `latest.json` последним.
5. Проверьте HTTPS-загрузку, SHA-256, обновление в Windows-приложении. Никакого автоматического запуска EXE без согласия пользователя.

## Безопасность и конфигурация

- В боевом боте необходимы SFTP-параметры `SKRYON_RELEASE_SFTP_HOST`, `SKRYON_RELEASE_SFTP_USER`, `SKRYON_RELEASE_SFTP_PRIVATE_KEY`, `SKRYON_RELEASE_SFTP_HOSTKEY_SHA256`; у SFTP-пользователя должен быть доступ только к каталогу статических релизов. Не используйте root.
- Ключ подписи обновлений **не должен** храниться на VPS. Бот получает подписанный JSON и проверяет его по закреплённому публичному ключу.
- Authenticode требуется по умолчанию. `SKRYON_RELEASE_ALLOW_UNSIGNED=1` разрешает администратору тестовый выпуск без Windows Authenticode, но **не отменяет** ECDSA-подпись JSON или проверку SFTP. Для стабильного публичного релиза оставьте этот параметр выключенным.
- Сами по себе номера версий в EXE не доказывают подлинность программы. Публикация закрыта, пока нет совпадающего манифеста.
- Перед развёртыванием на работающий бот пройдите все тесты и сохраните копию кода и состояния. Не перезапускайте VPN-службы ради обновления Telegram-бота.
- Публикация не изменяет `MIN_SUPPORTED_APP_VERSION_CODE` и не отключает текущие клиентские подключения. Повышение минимальной версии требует отдельного безопасного процесса.
