# Skryon orchestrator

Минимальный сервер для активации кодов Skryon.

Состав:
- SQLite база.
- API для проверки кода.
- Таблица кодов активации.
- Таблица активного сервера.

Запуск API:
python -m uvicorn api:app --host 0.0.0.0 --port 8080

Реальные токены и секреты не храним в репозитории. Их нужно задавать локально через переменные окружения.
