# Skryon orchestrator

Минимальный сервер для активации кодов Skryon.

Состав:
- SQLite база.
- API для проверки кода.
- Таблица кодов активации.
- Таблица активного сервера.

Запуск API:
python -m uvicorn api:app --host 0.0.0.0 --port 8080

Синхронизация конфигов:
- `POST /api/config/sync` держит запрос до 25 секунд и сразу возвращает новую ревизию после `/addconfig`, `/useconfig` или `/delconfig`.
- Запрос разрешён только коду, уже привязанному к указанному `deviceId` через `/api/activate`.
- Бот и API должны использовать один и тот же `DATABASE_PATH`.

Реальные токены и секреты не храним в репозитории. Их нужно задавать локально через переменные окружения.
